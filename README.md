This repository contains the main code used to train and evaluate the machine-learning models, conduct county-level spatial predictions, estimate uncertainty, and generate the figures for the manuscript “A straw-based agronomic management paradigm reshapes grain yield–soil carbon–greenhouse gas trade-offs.” The analysis compares artificial neural network, support vector machine, gradient boosting machine, and random forest models for predicting the effects of straw management on grain yield, soil organic carbon sequestration, CO2 emissions, and N2O emissions.
R version 4.5.2 was used for data processing, statistical analysis, model development, uncertainty estimation, and visualization. The required R packages should be installed and loaded before running the scripts; package dependencies and their uses are documented in the corresponding code files.
The repository includes the code and supporting data required to reproduce the principal numerical results, machine-learning analyses, county-level predictions, uncertainty estimates, and figures reported in the manuscript. The uncertainty analysis combines 100 bootstrap models with 1,000 Monte Carlo simulations for each county.
This repository contains research code rather than a standalone software package. Minor adjustments to file paths, software environments, or package versions may therefore be required. Technical assistance can be provided upon reasonable request.
